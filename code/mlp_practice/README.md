# MLP多层感知机回归练习

本目录记录使用PyTorch多层感知机完成回归任务的学习过程。

当前包含两个项目：

1. 二维函数拟合；
2. 模拟房价预测。

---

## 1. 二维函数拟合

代码：

```text
01_mlp_2d_function_prediction.py
```

任务是根据两个输入变量`x、y`预测目标值`z`。

### 实验版本

#### Version 1

输入范围：

```text
x, y ∈ [-3, 3]
```

目标函数：

```text
z = sin(x) + cos(y)
```

#### Version 2

输入范围扩大为：

```text
x, y ∈ [-10, 10]
```

目标函数仍为：

```text
z = sin(x) + cos(y)
```

#### Version 3

使用更复杂的非线性函数：

```text
z = sin(xy) + 0.1x² + cos(y)
```

#### Version 4

在Version 3基础上加入随机噪声：

```text
z = sin(xy) + 0.1x² + cos(y) + noise
```

该版本用于观察噪声对回归模型训练和预测结果的影响。

### MLP结构

```text
2个输入特征
↓
Linear(2, 32)
↓
ReLU
↓
Linear(32, 16)
↓
ReLU
↓
Linear(16, 1)
↓
预测z
```

### 主要学习内容

- NumPy与PyTorch模拟数据；
- CSV文件读取和保存；
- 训练集和测试集划分；
- StandardScaler；
- 防止使用测试集计算标准化参数；
- TensorDataset与DataLoader；
- MLP回归；
- MSELoss；
- Adam优化器；
- MAE、MSE、RMSE与R²；
- 目标反标准化；
- 模型保存；
- 新坐标预测。

## 2. 模拟房价预测

目录：

```text
houseprice/
```

代码：

```text
houseprice/houseprice.py
```

项目根据以下三个特征预测模拟房价：

- 房屋面积；
- 卧室数量；
- 房龄。

### 数据说明

房价数据由程序根据预先设定的数学关系和随机噪声生成。

```text
输入：面积、卧室数量、房龄
输出：模拟房价
样本数：500
```

> 该数据不是真实房地产数据，仅用于学习多特征回归和PyTorch训练流程。

### 模型结构

```text
3个输入特征
↓
Linear(3, 32)
↓
ReLU
↓
Linear(32, 16)
↓
ReLU
↓
Linear(16, 1)
↓
预测房价
```

### 主要学习内容

- 多特征回归；
- 人工数据生成；
- 输入特征标准化；
- Dataset与DataLoader；
- MLP训练；
- 测试集评价；
- MAE、RMSE与R²；
- 模型保存；
- 新房屋预测。
